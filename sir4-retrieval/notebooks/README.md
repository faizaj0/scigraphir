# Colab notebooks

The notebooks are generated by `../prep/build_*_notebook.py`; a generator's docstring is the
authoritative description of the experiment, and the first markdown cell of a notebook can
lag behind it. They run on Colab (A100), read `gfm-rag-adapted.zip` and a data bundle from
Google Drive, and write predictions and scores back to Drive. Trained checkpoints and
per-query predictions live on Drive, not in this repository.

| Notebook | Experiment | Thesis |
|---|---|---|
| `sir4_{cs,biology,physics,matsci}_ccmp_vs_control.ipynb` | In-field SIR-4 arms: multi-view scorer, + graph reasoner (control), + CCMP, each field trained on its own train split. | Table 9.1, SIR-4 columns |
| `tomato_ablations.ipynb`, `tomato_ccmp_ablation.ipynb` | Same arms on TOMATO-Star. | Table 9.1, TOMATO-Star columns |
| `colab_sir4_openie_ablation.ipynb`, `colab_tomato_openie_ablation.ipynb` | Construction control: same scorer and reasoner on the OpenIE entity graph ("+ Graph Reasoner (OpenIE graph)"). | Table 9.1 |
| `colab_sir4_hyb.ipynb` | Merged-graph variant with and without CCMP against the OpenIE row, four fields. | Ch. 9 analysis |
| `colab_routing_sir4_cs.ipynb`, `colab_routing_tomato.ipynb` | Routing baselines: no routing vs A*Net-style node selection vs RED-GNN-style edge attention vs CCMP, everything else shared. | Routing table |
| `colab_sir4_zeroshot_physics+biology_to_cs+matsci_standard.ipynb`, `..._cs+matsci_to_physics+biology_standard.ipynb` | Zero-shot transfer between SIR-4 fields, both directions, next to the six training-free baselines. | Table 9.3 (a) |
| `colab_rb_zeroshot.ipynb` | Zero-shot transfer to ResearchBench (TOMATO-Star-trained and SIR-4-trained checkpoints, all baselines, one scorer). | Table 9.3 (b) |
| `colab_mir_all.ipynb`, `mir_baselines.ipynb` | MIR: dense, LLM-expanded and graph baselines, and SciGraphIR trained on MIR. | Table 9.1 MIR column, Table 9.3 (b) |
| `sir4_baselines_all.ipynb`, `tomato_baselines.ipynb`, `llm_expansion_baselines_sir4.ipynb` | BM25, BGE-large, Qwen3-Embedding, SPECTER2, SciNCL, ReasonIR-8B, GFM-RAG, G-Reasoner, HyDE and MuGI through one scorer. | Table 9.1 baselines |
| `colab_scientific_paths.ipynb` | Top graph routes to selected cross-field golds under the trained model, with the CCMP gate per hop. | Qualitative analysis |
| `colab_table4_openie.ipynb` | Why CCMP changes a fixed path's attribution: gate interventions on the same weights. | Mechanism analysis |
| `colab_ccmp_gate_decomp.ipynb` | Which gates move a route's weight (layer and sender masks on the same weights). | Mechanism analysis |
| `colab_showcase_all.ipynb` | Ranks of every gold under every channel and arm, and gradient beam search for the worked examples. | Worked examples |

Other notebooks from the project (single-field baselines, explored variants such as CQIG,
per-document routing and the semantic-prior reasoner, per-field showcase and qualitative
runs) are regenerable from the generators in `../prep/` and are not included.
